# 演示视频脚本（5 分钟，1080p，普通话）

0:00–0:30 开场：介绍知枢 Agent —— 面向中小企业行政人事的私有文档 RAG + Agent + MCP 工具链助手，一句话痛点：制度散、表单重复做、怕答错。
0:30–1:30 知识库：点"导入制度文档"，展示已导入《入职》《离职》《转正考勤》三份制度，说明切片向量化、可溯源。
1:30–2:30 RAG 问答：问"试用期最长多久？转正要走哪些手续？"，展示回答末尾带制度来源、不编造。
2:30–3:30 Agent 工具：输入"给张三，技术部，工程师生成入职登记表"，展示 Agent 自动调用工具生成表单；再问"列一份入职待办清单"。
3:30–4:00 多模态：点麦克风，语音说"帮我列一份离职待办"，展示语音转文字并触发回答。
4:00–4:40 架构讲解：分层提示词、RAG 溯源、MCP 风格工具注册层、maxSteps 多步工具循环。
4:40–5:00 总结：真实场景价值 + 后续扩展。
